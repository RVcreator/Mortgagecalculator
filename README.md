Mortgage Calculator

This project is a beginner-friendly Python program that calculates monthly mortgage payments based on user inputs such as loan amount, interest rate, and loan term.

✨ Features

Accepts user input for principal, interest rate, and years

Calculates total monthly payments using a standard mortgage formula

Handles invalid input gracefully (optional enhancement)

Simple and easy-to-read code structure

🧠 Skills Practiced

Python basics (variables, input/output, conditionals, functions)

Arithmetic operations and formula application

User interaction with input()

Clean code formatting and logical structure

🛠️ How to Run

Clone this repository:

git clone https://github.com/RVcreator/mortgage-calculator.git


Navigate into the folder:

cd mortgage-calculator


Run the program:

python mortgage_calculator.py
